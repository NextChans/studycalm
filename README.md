# StudyCalm (스터디카페 소음 경고 웹앱 MVP)

스터디카페에 고정 설치한 태블릿에서 동작하는 정적 SPA 웹앱입니다.
마이크로 주변 소음을 실시간 측정하고, 배경소음 기준선(Baseline) 대비 설정한 임계치를 지속 초과할 경우 "조용히 해주세요" 안내 음성을 자동으로 송출합니다.

백엔드 서버 없이 정적 호스팅(Vercel)으로 구동되며, 프라이버시 보호를 위해 **오디오 데이터를 절대 녹음하거나 전송하지 않고 메모리 상에서 실시간 레벨(dBFS)만 계산**합니다.

---

## 🚀 주요 기능

1. **마이크 입력 및 RMS/dBFS 측정**
   - 브라우저 Web Audio API 기반 오디오 프로세싱.
   - 왜곡 방지를 위해 `echoCancellation`, `noiseSuppression`, `autoGainControl` 하드웨어 프로세싱 비활성화.
   - 시간영역 샘플 버퍼로부터 RMS를 계산하여 dBFS 변환 및 지수이동평균(EMA) 스무딩 적용.
2. **배경소음 보정 (Baseline Calibration)**
   - 앱 시작 시 30초간(설정 가능) 주변 소음을 측정하여 **중앙값(Median)**을 기준선(Baseline)으로 저장.
   - 임계치는 `Baseline + N dB` (기본 +15dB) 상대값으로 자동 설정.
   - 환경 변화 시 원클릭 `재보정` 기능 지원.
3. **상태 머신 기반 판정 로직 (NoiseStateMachine)**
   - `IDLE` → `CALIBRATING` → `MONITORING` ⇄ `EXCEEDING` → `ALERTING` → `COOLDOWN` → `MONITORING`
   - 책 떨어뜨림 등 순간 소음 무시 (기본 1500ms 이상 연속 초과 시에만 경고).
   - 일시적인 소음 하강을 허용하는 히스테리시스(기본 200ms) 지원.
   - **피드백 루프 방지:** 음성 안내 재생 중 및 종료 후 1500ms 동안은 마이크 입력을 무시하여 스피커 소리가 다시 마이크로 유입되는 현상 차단.
   - 과도한 연속 방송 방지를 위한 쿨다운(기본 45초).
4. **안내 음성 관리 (커스텀 음성 업로드 및 직접 녹음) & TTS 폴백**
   - **태블릿 현장 파일 업로드:** 관리자 설정 창에서 직접 녹음한 `.mp3`, `.wav`, `.m4a` 등 음원 파일을 선택하여 즉시 등록.
   - **태블릿 현장 즉석 녹음 🎙️:** 별도 파일이 없어도 설정 창에서 [지금 직접 녹음] 버튼을 눌러 점주님 육성으로 현장에서 5초간 즉석 녹음 후 적용 가능.
   - **로컬 영구 보관:** 브라우저 IndexedDB에 저장되어 서버 전송 없이 영구 보존되며, [미리 듣기] 및 [기본음으로 복원] 제공.
   - **폴백:** 등록된 음원이 없을 시 `/sounds/` 디렉토리 파일 로테이션 재생 및 Web Speech API(`speechSynthesis`, ko-KR)로 폴백.
5. **태블릿 가로(Landscape) 다크모드 UI**
   - 대형 실시간 dBFS 게이지 미터, 기준선/임계치 마커선, 초과 지속 프로그레스 바.
   - 관리자 PIN 4자리로 잠금 보호되는 설정 패널.
   - 관리자 PIN은 코드에 하드코딩되지 않고 최초 실행 시 사용자가 직접 설정 (SHA-256 해시로 저장).
   - 하단 고정 법적 안심 문구: *"소음 측정만 하며, 녹음·저장하지 않습니다"*.
   - 당일 경고 횟수 카운터 (localStorage, 자정에 자동 0회 리셋).
6. **운영 안정성 & PWA**
   - Screen Wake Lock API 적용 및 `visibilitychange` 시 자동 재획득.
   - 탭 백그라운드 전환 감지 및 경고 배너 표시.
   - 마이크 트랙 종료 감지 시 자동 재연결 시도 및 실패 시 안내 UI.
   - Service Worker 앱 셸/사운드 오프라인 프리캐시 & 새 버전 배포 시 새로고침 유도 배너.
7. **관리자 원격 리모컨 (여러 태블릿 통합 관리) 📱**
   - **QR 페어링 (관리자 PIN 필요):** 태블릿 상단 `[📱 원격 리모컨]` → 관리자 PIN 입력 후 표시되는 QR을 스캔하면 리모컨에 태블릿이 추가됩니다. 태블릿마다 스캔하면 한 리모컨에서 여러 태블릿을 관리할 수 있습니다.
   - **원격 방송 / 중지:** 개별 태블릿 또는 전체 태블릿에 즉시 주의 방송, 맞춤 멘트(TTS) 송출, 재생 중인 방송 즉시 중지.
   - **원격 기준·임계치 조정:** 태블릿별 배경소음 기준(자동/수동)과 경고 임계치(기준+N dB / 절대값)를 원격으로 조정하면 태블릿에 즉시 적용·저장됩니다.
   - **실시간 상태:** 태블릿별 실시간 dB, 상태, 오늘 경고 횟수, 소리 출력 허용 여부, 태블릿 응답 여부 확인.
   - **보안:** 페어링 키(256bit)는 QR의 URL fragment(`#k=`)로만 전달되어 서버 로그에 남지 않고, 모든 메시지는 AES-GCM으로 종단간 암호화·인증됩니다. 키 없이 중계 채널을 엿보거나 명령을 위조할 수 없으며, 태블릿에서 키를 재발급하면 기존 리모컨이 모두 차단됩니다.
   - **다중 중계:** Supabase Realtime(443 포트) + EMQX + HiveMQ 공용 MQTT에 동시에 연결해, 공통으로 닿는 중계가 하나만 있어도 동작합니다.

## 🛠️ 기술 스택

- **Frontend:** React 18, TypeScript (Strict), Vite
- **Styling:** Tailwind CSS (Dark theme, Tablet Landscape layout)
- **Audio Processing:** Web Audio API (`AudioContext`, `AnalyserNode`) - 외부 라이브러리 제로
- **Storage:** LocalStorage (설정값, SHA-256 PIN 해시, 일일 카운터)
- **Testing:** Vitest (상태 머신, RMS 감지기, EMA 필터, PIN 인증, 카운터)
- **Lint & Format:** ESLint 9, Prettier
- **Deployment:** Vercel (정적 SPA 호스팅, 보안 헤더 및 PWA 캐시 전략 적용)

## 🔊 경고 음성 파일 교체 방법

모든 태블릿은 같은 경고 멘트를 내도록 **항상 `public/sounds/alert-1.wav` 한 파일만** 재생합니다(로테이션 없음).
관리자 설정에서 커스텀 음원을 녹음·업로드한 태블릿은 그 음원을 우선 재생합니다(기기별 저장).

기본 음원을 교체하려면:
1. 안내 멘트를 녹음하거나 AI TTS로 음원(wav/mp3) 생성
2. `public/sounds/alert-1.wav`를 덮어쓰고 `src/config/defaults.ts`·`SoundPlayer.ts`의 `?v=` 버전을 올림 (기존 태블릿 캐시 우회)
3. `public/sw.js`의 `CACHE_NAME`과 프리캐시 목록 버전도 함께 올림 (새 서비스워커는 자동 적용됨)
4. 음원을 재생할 수 없으면 차임 + 서버 TTS("조용히 해주세요.")로 자동 대체됩니다.

## 🌐 원격 중계(Supabase) 설정 — 권장

공용 MQTT 브로커는 8084/8884 포트를 사용하므로 **매장 Wi-Fi·사내망·일부 통신사 환경에서 차단**될 수 있습니다.
어떤 네트워크에서도 원격 리모컨이 동작하려면 443 포트를 쓰는 Supabase Realtime을 설정하세요. (무료 플랜으로 충분, DB 테이블 불필요)

1. [supabase.com](https://supabase.com)에서 프로젝트 생성
2. **Project Settings → API**에서 `Project URL`, `anon`(publishable) 키 복사
3. **Realtime → Settings**에서 *Allow public access*(공개 채널 허용)가 켜져 있는지 확인
   - 메시지는 앱에서 종단간 암호화되므로 공개 채널이어도 내용 노출/위조가 불가능합니다.
4. Vercel 프로젝트 **Settings → Environment Variables**에 등록 후 재배포
   - `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (빌드 시 주입되는 `VITE_` 변수)
5. 태블릿의 `[📱 원격 리모컨]` 창에서 `● Supabase`가 초록색이면 완료

> 무료 플랜 메시지 쿼터 보호를 위해 태블릿은 리모컨이 화면을 보고 있을 때만(최근 15초 내 PING) 1초 주기 텔레메트리를 보냅니다.

### 음성 안내(TTS)
원격 맞춤 멘트는 Vercel 서버리스 함수 `/api/tts`가 한국어 mp3를 생성해 모든 기기에서 동일하게 재생합니다.
운영 환경에서는 Vercel 서버 환경변수 `GOOGLE_TTS_API_KEY`(Google Cloud Text-to-Speech)를 설정하는 것을 권장합니다.
미설정 시 비공식 Google Translate TTS로 폴백하며, 모두 실패하면 기기 내장 음성(speechSynthesis)을 사용합니다.

## 🕶 숨김 설치 가이드 (휴게실 권장)

태블릿을 숨겨 설치할 때는 다음 기능을 함께 사용하세요.

| 기능 | 위치 | 설명 |
|---|---|---|
| 숨김 모드 | 설정 / 리모컨 | 화면은 켜둔 채(웹앱은 화면이 꺼지면 측정·통신이 멈춤) 검은 화면만 표시. 터치하면 30초간 표시 |
| 자동 재개 | 자동 | 측정 중 재부팅·새로고침되면 터치 없이 측정을 다시 시작 (마이크 권한이 허용된 경우) |
| 이상 알림 | 리모컨 | 응답 없음, 측정 멈춤, 소리 출력 미허용, 충전기 분리, 배터리 부족 시 리모컨 상단 경고 + 진동 |
| 시간대 스케줄 | 설정 / 리모컨 | 요일·시간대별 자동 경고 음소거 또는 임계치 변경 (자정 넘는 구간 지원, 위 규칙 우선) |
| 정시 안내 방송 | 설정 / 리모컨 | 정해진 요일·시각에 안내 멘트(텍스트 음성) 또는 리모컨 녹음 음성을 1~3회 방송. 음소거와 무관하게 재생, 하루 1회, 시각 후 2분 지나면 건너뜀. 리모컨에서 '지금 한 번 방송'으로 미리 듣기 |
| 맞춤 멘트 편집 | 리모컨 | 리모컨 프리셋 멘트(최대 6개)를 직접 수정·추가·삭제 (관리자 폰에 저장) |
| 배터리 표시 | 리모컨 | 배터리 잔량·충전 여부 (Android Chrome 지원, iPad Safari 미지원) |

- 숨긴 위치에서도 마이크 구멍이 막히지 않게 두고, 설치 후 배경소음 재측정 및 리모컨 실시간 dB로 임계치를 맞추세요.
- **Android 태블릿 + 홈 화면 앱(PWA)** 조합은 재시작 후에도 터치 없이 소리까지 복구됩니다. iPad는 재시작 후 화면을 한 번 터치해야 소리가 나며, 리모컨에 '소리 출력 미허용' 경고가 표시됩니다.
- 충전기를 항상 연결하고 통풍되는 곳에 두세요.

### iPad 배터리·충전기 알림 (단축어 자동화)

Safari는 개인정보 보호를 이유로 배터리 정보(Battery Status API)를 웹에 제공하지 않아, iPad는 리모컨에 배터리가 표시되지 않습니다.
대신 iPadOS 기본 **단축어** 앱으로 관리자 폰에 직접 문자 알림을 받을 수 있습니다 (앱이 멈춰 있어도 동작).

1. iPad **단축어** 앱 → **자동화** 탭 → **새로운 자동화**
2. 트리거 선택
   - **충전기** → *연결 해제 시* (충전기 빠짐 알림)
   - **배터리 잔량** → *20% 미만으로 떨어질 때* (배터리 부족 알림)
3. **즉시 실행** 선택 (실행 전 확인 끄기)
4. 동작 추가 → **메시지 보내기** → 받는 사람: 관리자 번호, 내용: 예) `1층 태블릿 충전기가 분리되었습니다`
5. 트리거별로 1~4를 반복해 자동화를 각각 만듭니다.

- 배터리 수명을 위해 iPad **설정 → 배터리 → 충전 최적화(최적화된 충전)**를 켜 두세요.
- 배터리가 소진되어 iPad가 꺼지면 리모컨에 **🚨 응답 없음** 경고가 표시됩니다.
- **iPad는 Safari와 홈 화면 앱의 저장소가 분리**되어 있습니다. 반드시 홈 화면 아이콘으로 연 상태에서 QR 페어링하고 이후에도 아이콘으로만 여세요. (Safari에서 페어링 후 아이콘으로 열면 새 페어링 키가 생성되어 QR을 다시 스캔해야 합니다.)
- 재부팅 후 리모컨에서 '응답 없음'이 계속되면 태블릿 [원격 리모컨] 창의 보안 확인 코드와 리모컨 카드의 확인 코드를 비교하세요. 다르면 태블릿 저장소가 초기화된 것입니다.

## 📱 권장 기기 및 매장 설치 가이드

### 1. 전원 및 디스플레이 설정
- **상시 전원 충전:** 배터리 절전 모드로 진입하면 브라우저 타이머가 스로틀링될 수 있으므로 충전기를 상시 연결해 두세요.
- **화면 자동 잠금 해제:** 태블릿 OS 설정(Android: `설정 > 디스플레이 > 화면 꺼짐 시간 > 안 함` 또는 개발자 옵션 `충전 중 화면 켜짐 유지` 활성화)에서 화면이 절대 꺼지지 않도록 설정합니다.

### 2. 홈 화면에 PWA 설치
1. 태블릿 브라우저(Android Chrome 또는 iOS Safari)로 배포된 URL에 접속합니다.
2. 브라우저 메뉴에서 **[홈 화면에 추가]** 또는 **[앱 설치]**를 선택합니다.
3. 홈 화면에 생성된 아이콘을 터치하여 실행하면 브라우저 주소창과 툴바가 사라진 **전체화면(Standalone) 키오스크 모드**로 실행됩니다.

### 3. iOS (iPad / iPhone) 주의사항
> ⚠️ **중요 (iOS Safari 백그라운드 제한):**
> iOS WebKit 정책상 사용자가 전원 버튼을 눌러 화면을 잠그거나 다른 앱으로 전환하면 **마이크 오디오 입력 스트림이 브라우저 레벨에서 즉시 강제 중단(Mute)**됩니다.
> 따라서 iPad를 모니터링 기기로 사용할 때는 화면 꺼짐 방지(Wake Lock)가 항상 유지되도록 화면을 켜둔 채 거치대 등에 고치하여 운용해야 합니다.

## 🔒 보안 및 캐시 정책 (`vercel.json`)

- **Permissions-Policy:** `microphone=(self), camera=(), geolocation=()` (오직 자체 도메인에서만 마이크 권한을 허용하며 카메라/위치 정보는 원천 차단)
- **Content-Security-Policy (CSP):**
  - `default-src 'self'`: 외부 스크립트/리소스 로딩 원천 차단
  - `media-src 'self' blob:`: 자체 음원 파일 및 TTS 오디오 블롭만 허용
  - `script-src 'self'`: 정적 번들 스크립트만 실행
- **캐시 제어:**
  - `/sw.js`, `/index.html`, `/manifest.webmanifest`: `Cache-Control: no-cache`를 강제하여 버전 업데이트 시 서비스워커와 메인 HTML이 즉시 갱신되도록 보장
  - `/assets/*`: 빌드 시 생성되는 해시 파일명 에셋으로 `max-age=31536000, immutable` 적용
  - `/sounds/*`: 오프라인 캐시 및 네트워크 트래픽 절감을 위해 적정 캐시 적용
